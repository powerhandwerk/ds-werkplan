Die Info-Zeile stellt ein Icon an die erste Zeile und den Text daneben.

## Wann

- Für kurze Zusatzangaben auf Arbeitsseiten.
- `gross` setzt `grad-14` und eine dunklere Schrift.

## Was der Verbraucher liefert

| Prop | Typ | Standard | Bedeutung |
|---|---|---|---|
| `icon` | `ReactNode` | Pflicht | Icon an der ersten Zeile. |
| `children` | `ReactNode` | Pflicht | Text. |
| `gross` | `boolean` | `false` | Größere Fassung. |

Import aus `@powerhandwerk/ds-werkplan/Arbeitsflaeche`, im Bündel `DsWerkplan.Info`.

## Was man lässt

- Icons vor jeder Zeile: Icons stehen dort, wo sie etwas bedeuten.
