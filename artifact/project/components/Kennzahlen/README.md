Kennzahlen stellen zwei bis vier Kennzahlen in eine Reihe, schmal untereinander.

## Wann

- Unter dem Titel eines Berichtsblatts oder in einer Position. Der Baustein schaltet über seine eigene Breite.

## Was der Verbraucher liefert

| Prop | Typ | Standard | Bedeutung |
|---|---|---|---|
| `zahlen` | `readonly KennzahlDaten[]` | Pflicht | Je Zahl `kopf`, `wert` und `text`. |

Import aus `@powerhandwerk/ds-werkplan/Berichtsteile`, im Bündel `DsWerkplan.Kennzahlen`.

## Was man lässt

- Mehr als vier Zahlen in einer Reihe.
