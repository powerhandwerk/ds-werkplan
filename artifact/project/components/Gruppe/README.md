Die Gruppe ist ein Gruppenkopf in der Liste, mit Titel links und Zahl rechts.

## Wann

- Zwischen Listenzeilen, um sie zu ordnen. Sie ist ein `<li>` und steht direkt in `Liste`.

## Was der Verbraucher liefert

| Prop | Typ | Standard | Bedeutung |
|---|---|---|---|
| `titel` | `string` | Pflicht | Titel der Gruppe. |
| `zahl` | `number` | Pflicht | Zahl der Einträge. |

Import aus `@powerhandwerk/ds-werkplan/Arbeitsflaeche`, im Bündel `DsWerkplan.Gruppe`.

## Was man lässt

- Die Gruppe außerhalb einer `Liste`.
